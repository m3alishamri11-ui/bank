# نظام اكتشاف الاحتيال البنكي (Bank Fraud Detection System)

## 📌 عن المشروع
هذا المشروع عبارة عن نظام ذكاء اصطناعي وتطبيق ويب متكامل يهدف إلى تحليل البيانات واكتشاف عمليات الاحتيال البنكية. تم بناء النموذج وتدريبه باستخدام تقنيات تعلم الآلة (Machine Learning) لحماية العمليات المالية.

## 📁 هيكل المشروع
* `train.py`: الكود الخاص بتدريب وبناء نموذج الذكاء الاصطناعي.
* `fraud_model.pkl`: النموذج المدرب الجاهز للتوقع واكتشاف الاحتيال.
* `scaler.pkl`: ملف معالجة وتجهيز البيانات.
* `app.py` / `main.py`: ملفات تشغيل تطبيق الويب (الواجهة الخلفية).
* `index.html` / `style.css`: ملفات تصميم واجهة المستخدم.
